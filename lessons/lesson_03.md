# Урок 3. Фильтрация строк через WHERE

---

## Производственный контекст

Руслан, на прошлом уроке ты узнал, как выбирать конкретные колонки. Но часто нужно не просто «все строки таблицы», а только те, которые соответствуют условию.

На производстве кресел это нужно каждый день:
- какие материалы сейчас активны;
- какие модели кресел не тестовые;
- какие строки плана уже утверждены.

Фильтрация строк — это команда WHERE.

---

## Теория

### Команда WHERE

WHERE задаёт условие отбора строк. Если строка подходит — PostgreSQL показывает её. Если нет — пропускает.

Базовый синтаксис:

```sql
SELECT
    column_1,
    column_2
FROM table_name
WHERE condition;
```

Обрати внимание на **порядок**: SELECT → FROM → WHERE. Его нельзя нарушать.

### Простые условия

- `WHERE status = 'active'` — статус равен active
- `WHERE category = 'fabric'` — категория равна fabric
- `WHERE current_price > 2000` — цена больше 2000

### Кавычки для текста

Текстовые значения обязательно в **одинарных кавычках**: `'active'`, `'fabric'`.

Числа в кавычках не нужны: `2000`, `38`.

Если забыть кавычки вокруг текста, PostgreSQL подумает, что это имя колонки, и выдаст ошибку.

---

## Пример SQL

Найдём все активные модели кресел:

```sql
SELECT
    model_code,
    model_name,
    category,
    status
FROM chair_models
WHERE status = 'active';
```

---

## Разбор результата

Запрос вернёт только те строки chair_models, где status = 'active'.

Модели со статусом test или archived не попадут в результат. Для экономиста это значит: в отчёте только те модели, которые реально используются в производстве.

---

## Типичные ошибки студентов

1. **Забывает кавычки вокруг текста.** `WHERE status = active` — ошибка. Нужно `'active'`.
2. **Пишет WHERE после FROM, но до SELECT.** Нарушение порядка слов.
3. **Использует WHERE без SELECT и FROM.** WHERE — только часть запроса, не самостоятельная команда.
4. **Путает = и <>.** = ищет совпадение, <> исключает значение.

## Практическое задание

🎯 **ЗАДАНИЕ**

Найди все активные модели кресел из таблицы chair_models.

Покажи колонки:
- model_code
- model_name
- category
- status
- standard_labor_minutes

**Критерии проверки:**
- Использована таблица chair_models
- В запросе есть SELECT, FROM и WHERE
- Условие проверяет status = 'active'
- Выбраны только колонки из условия

---

## Разбор решения

```sql
SELECT
    model_code,
    model_name,
    category,
    status,
    standard_labor_minutes
FROM chair_models
WHERE status = 'active';
```

Разберём:
- SELECT — выбираем колонки
- FROM chair_models — таблица с моделями кресел
- WHERE status = 'active' — оставляем только активные строки
- ; — конец

Почему status в кавычках: 'active' — это текст. PostgreSQL отличает текст от имён колонок по кавычкам.

---

## Почему это пригодится

Экономисту не нужны тестовые и архивные модели в отчёте. WHERE позволяет сразу отфильтровать лишнее и работать только с актуальными данными.
