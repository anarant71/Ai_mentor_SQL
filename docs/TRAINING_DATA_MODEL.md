# Training Data Model

Документ описывает учебную базу данных мебельного производства для SQL-практики. Модель предназначена для задач по BOM, материалам, складу, производственному плану, фактическому выпуску, поставщикам, себестоимости и автоматизации.

Это логическое описание данных. На текущем этапе SQL-скрипты и реальные таблицы не создаются.

## Общая идея модели

Учебная база должна имитировать работу производства офисных кресел:

- есть модели кресел;
- для каждой модели есть спецификация BOM;
- BOM содержит материалы и нормы расхода;
- материалы закупаются у поставщиков;
- склад хранит остатки и историю движений;
- производство планирует выпуск кресел;
- производство фиксирует фактический выпуск;
- экономист сравнивает план, факт, потребность материалов, остатки и себестоимость.

## Связи верхнего уровня

```text
chair_models 1--N bom_headers
bom_headers 1--N bom_lines
materials 1--N bom_lines
materials 1--N warehouse_stocks
materials 1--N warehouse_movements
suppliers 1--N materials
chair_models 1--N production_plan
chair_models 1--N production_output
production_plan 1--N production_output
```

## `chair_models`

Назначение: справочник моделей офисных кресел, которые производятся или планируются к производству.

Основные поля:

- `id` - уникальный идентификатор модели.
- `model_code` - внутренний код модели кресла.
- `model_name` - название модели.
- `category` - категория кресла: операторское, руководительское, конференц, детское.
- `status` - статус модели: активная, архивная, тестовая.
- `standard_labor_minutes` - норматив трудозатрат на одну единицу.
- `created_at` - дата создания записи.
- `updated_at` - дата обновления записи.

Связи:

- одна модель может иметь несколько версий BOM в `bom_headers`;
- одна модель может встречаться во многих строках `production_plan`;
- одна модель может встречаться во многих строках `production_output`.

## `suppliers`

Назначение: справочник поставщиков материалов и комплектующих.

Основные поля:

- `id` - уникальный идентификатор поставщика.
- `supplier_code` - внутренний код поставщика.
- `supplier_name` - название поставщика.
- `contact_name` - контактное лицо.
- `phone` - телефон.
- `email` - email.
- `city` - город поставщика.
- `status` - статус: активный, резервный, заблокированный.
- `created_at` - дата создания записи.

Связи:

- один поставщик может быть основным поставщиком для многих материалов в `materials`;
- поставщик используется для анализа закупок, дефицита и рисков поставки.

## `materials`

Назначение: справочник материалов, комплектующих и полуфабрикатов, используемых в производстве кресел.

Основные поля:

- `id` - уникальный идентификатор материала.
- `material_code` - артикул или внутренний код материала.
- `material_name` - название материала.
- `category` - категория: ткань, фанера, металл, пластик, механизм, колесо, фурнитура, упаковка.
- `unit` - единица измерения: м, м2, кг, шт, комплект, рулон.
- `default_supplier_id` - основной поставщик.
- `current_price` - текущая учетная или закупочная цена.
- `min_stock_quantity` - минимальный желательный остаток.
- `status` - статус материала: активный, архивный, заменяемый.
- `created_at` - дата создания записи.
- `updated_at` - дата обновления записи.

Связи:

- `default_supplier_id` ссылается на `suppliers.id`;
- один материал может входить во многие строки BOM в `bom_lines`;
- один материал имеет текущий остаток в `warehouse_stocks`;
- один материал может иметь много движений в `warehouse_movements`.

## `bom_headers`

Назначение: заголовки спецификаций BOM для моделей кресел. Таблица хранит версии BOM и их статус.

Основные поля:

- `id` - уникальный идентификатор BOM.
- `chair_model_id` - модель кресла.
- `bom_code` - код спецификации.
- `version` - номер или название версии.
- `status` - статус BOM: черновик, активная, архивная.
- `valid_from` - дата начала действия версии.
- `valid_to` - дата окончания действия версии.
- `comment` - пояснение к версии BOM.
- `created_at` - дата создания записи.
- `updated_at` - дата обновления записи.

Связи:

- `chair_model_id` ссылается на `chair_models.id`;
- одна модель кресла может иметь несколько версий BOM;
- один BOM содержит много строк в `bom_lines`;
- активный BOM используется для расчета потребности материалов и себестоимости.

## `bom_lines`

Назначение: строки спецификации BOM. Каждая строка показывает, какой материал и в каком количестве нужен для производства одной единицы модели кресла.

Основные поля:

- `id` - уникальный идентификатор строки BOM.
- `bom_header_id` - заголовок BOM.
- `material_id` - материал или комплектующее.
- `quantity_per_unit` - норма расхода на одно кресло.
- `scrap_percent` - процент технологических отходов или запаса.
- `line_type` - тип строки: основной материал, комплектующее, упаковка, расходник.
- `comment` - комментарий технолога или экономиста.
- `created_at` - дата создания записи.
- `updated_at` - дата обновления записи.

Связи:

- `bom_header_id` ссылается на `bom_headers.id`;
- `material_id` ссылается на `materials.id`;
- строки BOM используются вместе с `production_plan` для расчета потребности материалов;
- строки BOM используются вместе с `materials.current_price` для расчета материальной себестоимости.

## `warehouse_stocks`

Назначение: текущие остатки материалов на складе.

Основные поля:

- `id` - уникальный идентификатор записи остатка.
- `material_id` - материал.
- `warehouse_name` - склад или зона хранения.
- `quantity_on_hand` - фактический остаток.
- `reserved_quantity` - зарезервированное количество под производство.
- `available_quantity` - доступное количество.
- `last_counted_at` - дата последней инвентаризации или сверки.
- `updated_at` - дата обновления остатка.

Связи:

- `material_id` ссылается на `materials.id`;
- один материал может иметь остатки на нескольких складах или зонах;
- остатки сравниваются с потребностью, рассчитанной по `production_plan` и `bom_lines`;
- остатки могут объясняться историей движений из `warehouse_movements`.

## `warehouse_movements`

Назначение: история движений материалов на складе: приход, списание, перемещение, корректировка и возврат.

Основные поля:

- `id` - уникальный идентификатор движения.
- `material_id` - материал.
- `movement_date` - дата движения.
- `movement_type` - тип движения: приход, списание, перемещение, корректировка, возврат.
- `quantity` - количество движения.
- `warehouse_name` - склад или зона хранения.
- `document_number` - номер первичного документа.
- `reason` - причина движения.
- `production_output_id` - связанный выпуск, если движение отражает списание на производство.
- `created_at` - дата создания записи.

Связи:

- `material_id` ссылается на `materials.id`;
- `production_output_id` может ссылаться на `production_output.id`;
- движения используются для анализа расхода материалов, корректировок и причин изменения остатков;
- агрегированные движения должны объяснять изменение остатков в `warehouse_stocks`.

## `production_plan`

Назначение: план выпуска кресел по датам, сменам, моделям или заказам.

Основные поля:

- `id` - уникальный идентификатор плановой строки.
- `plan_date` - дата планируемого выпуска.
- `chair_model_id` - модель кресла.
- `planned_quantity` - плановое количество к выпуску.
- `shift_name` - смена или производственный участок.
- `plan_version` - версия плана.
- `status` - статус строки плана: черновик, утверждено, отменено, выполнено.
- `created_at` - дата создания записи.
- `updated_at` - дата обновления записи.

Связи:

- `chair_model_id` ссылается на `chair_models.id`;
- плановая строка может иметь связанные строки фактического выпуска в `production_output`;
- план используется вместе с активным BOM для расчета потребности материалов;
- план используется для сравнения с фактом выпуска.

## `production_output`

Назначение: фактический выпуск кресел по датам, моделям, сменам и плановым строкам.

Основные поля:

- `id` - уникальный идентификатор факта выпуска.
- `output_date` - дата фактического выпуска.
- `chair_model_id` - модель кресла.
- `production_plan_id` - связанная строка плана.
- `produced_quantity` - фактически выпущенное количество.
- `defect_quantity` - количество брака.
- `shift_name` - смена или производственный участок.
- `comment` - комментарий мастера, технолога или экономиста.
- `created_at` - дата создания записи.

Связи:

- `chair_model_id` ссылается на `chair_models.id`;
- `production_plan_id` может ссылаться на `production_plan.id`;
- фактический выпуск сравнивается с `production_plan.planned_quantity`;
- фактический выпуск может быть связан со списаниями материалов в `warehouse_movements`.

## Типовые учебные вопросы к модели

- Какие материалы нужны для выполнения плана выпуска на неделю?
- Каких материалов не хватает с учетом текущих складских остатков?
- Какие модели кресел имеют самую высокую материальную себестоимость?
- Какие материалы чаще всего корректируются на складе?
- По каким моделям есть отклонение факта от плана?
- Какие строки BOM не имеют цены материала?
- Какие материалы ниже минимального остатка?
- Как изменилась цена ключевых материалов по последним поставкам?

## Правила для учебных данных

- Все названия таблиц и полей должны оставаться связанными с мебельным производством.
- Не использовать абстрактные учебные сущности вне предметной области.
- Данные должны позволять решать задачи от простого `SELECT` до CTE и оконных функций.
- В данных должны быть нормальные рабочие ситуации и намеренные проблемы: пропуски цен, нулевые нормы, отрицательные остатки, отмененные планы, частичный выпуск.
- Модель должна поддерживать будущую автоматизацию через n8n: отчеты по дефициту, критическим остаткам, план-факту и ошибкам данных.
