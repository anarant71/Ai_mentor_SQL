# Урок 1. Первый SQL-запрос

---

## Производственный контекст

Руслан, ты работаешь экономистом на производстве офисных кресел. В твоей базе данных хранится всё: модели кресел, материалы, складские остатки, планы производства.

Первый шаг — научиться просто «заглядывать» в таблицы и смотреть, какие данные там есть. Это как открыть Excel-файл и увидеть содержимое листа — только теперь ты будешь делать это через SQL.

---

## Теория

### Что такое SQL

SQL (Structured Query Language) — это язык запросов. На нём ты разговариваешь с базой данных: задаёшь вопросы и получаешь ответы в виде таблиц.

Самая первая и главная команда SQL — SELECT.

### Команда SELECT

SELECT переводится как «выбери». Ты говоришь базе: «выбери такие-то данные».

Чтобы выбрать данные, нужно указать откуда их брать — команда FROM.

Вместе это выглядит так:

```sql
SELECT * FROM chair_models;
```

Разберём по частям:

- **SELECT** — «покажи»
- **\*** — «все колонки»
- **FROM** — «из таблицы»
- **chair_models** — имя таблицы
- **;** — точка с запятой, конец запроса

Точка с запятой в конце обязательна. Если её забыть, база будет ждать продолжения.

---

## Пример SQL

Выполни запрос к таблице materials:

```sql
SELECT * FROM materials;
```

---

## Разбор результата

Ты увидишь таблицу с материалами и комплектующими.

В результате будут колонки:

- id — уникальный номер материала
- material_code — код материала
- material_name — название
- category — категория: ткань, металл, фанера
- unit — единица измерения: м2, шт, кг
- current_price — текущая цена
- status — статус

Сколько строк ты видишь? Должно быть не меньше 20.

---

## Типичные ошибки студентов

1. **Забывает точку с запятой.** База ждёт продолжения. Допиши ; и нажми Enter.
2. **Неправильное имя таблицы.** materials, а не material или Materials.
3. **SELECT * без FROM.** Нужно обязательно указать таблицу.

---

## Практическое задание

🎯 **ЗАДАНИЕ**

Выполни SELECT * FROM materials и посмотри, какие данные там хранятся.

- Посчитай, сколько строк вернулось
- Обрати внимание на категории материалов

**Проверка:** запрос выполнился, таблица не пустая.

---

## Разбор решения

```sql
SELECT * FROM materials;
```

SELECT * — все колонки. FROM materials — таблица materials. ; — конец.

---

## Почему это пригодится

Экономист каждый день проверяет справочники: какие материалы активны, обновились ли цены. С SQL — 5 секунд.
