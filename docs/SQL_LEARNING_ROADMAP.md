# SQL Learning Roadmap

Roadmap построен для ученика, который работает экономистом на производстве офисных кресел. Все учебные примеры должны использовать предметную область мебельного производства: BOM, материалы, склад, производство, планирование, себестоимость, нормы расхода и автоматизация.

Не использовать абстрактные учебные таблицы вне контекста мебельного производства.

## Учебный контекст

Рекомендуемые учебные таблицы для примеров и заданий:

- `chair_models` - модели офисных кресел.
- `bom_headers` - версии спецификаций BOM.
- `bom_lines` - строки BOM с материалами и нормами расхода.
- `materials` - справочник материалов и комплектующих.
- `material_categories` - категории материалов: ткань, фанера, металл, пластик, фурнитура, упаковка.
- `warehouse_stocks` - остатки материалов на складе.
- `stock_movements` - движения материалов: приход, списание, перемещение, корректировка.
- `production_orders` - производственные заказы.
- `production_plan` - план выпуска по датам и моделям кресел.
- `production_output` - фактический выпуск.
- `material_prices` - цены закупки материалов.
- `labor_norms` - нормы трудозатрат.
- `cost_calculations` - расчет себестоимости модели или заказа.
- `suppliers` - поставщики материалов.
- `purchase_orders` - заказы поставщикам.

## Цель Roadmap

Научиться использовать PostgreSQL для ежедневной аналитики и автоматизации работы экономиста:

- получать данные по материалам, остаткам, BOM и производству;
- проверять нормы расхода и себестоимость;
- сравнивать план и факт выпуска;
- находить дефицит материалов;
- готовить SQL-запросы для отчетов, n8n-автоматизаций и будущих AI-сценариев.

## Модуль 1. Основы SELECT

Цель: уверенно читать данные из одной таблицы.

Темы:

- `SELECT`;
- `FROM`;
- `WHERE`;
- `ORDER BY`;
- `LIMIT`;
- алиасы колонок;
- простые вычисления в запросе.

Примеры задач:

- вывести список активных моделей кресел из `chair_models`;
- найти материалы категории `fabric` в `materials`;
- показать остатки материалов ниже минимального уровня из `warehouse_stocks`;
- отсортировать материалы по текущей цене закупки;
- рассчитать стоимость одной строки BOM как `quantity_per_unit * price`.

Практический результат: ученик умеет быстро получать нужный фрагмент данных из справочников и складских таблиц.

## Модуль 2. Фильтрация и логические условия

Цель: научиться писать точные условия отбора.

Темы:

- `AND`, `OR`, `NOT`;
- `IN`, `BETWEEN`, `LIKE`, `ILIKE`;
- работа с `NULL`;
- фильтрация по датам.

Примеры задач:

- найти материалы без указанного поставщика;
- вывести производственные заказы за текущий месяц;
- найти позиции BOM, где норма расхода больше заданного порога;
- найти складские движения типа `write_off` или `adjustment`;
- найти модели кресел, в названии которых есть слово `manager`.

Практический результат: ученик умеет строить запросы для контроля данных и поиска проблемных записей.

## Модуль 3. Агрегации и группировки

Цель: получать управленческие показатели из производственных данных.

Темы:

- `COUNT`;
- `SUM`;
- `AVG`;
- `MIN`, `MAX`;
- `GROUP BY`;
- `HAVING`.

Примеры задач:

- посчитать общий остаток материалов по категориям;
- рассчитать фактический выпуск кресел по дням;
- найти среднюю цену закупки по каждой категории материалов;
- посчитать количество строк BOM по каждой модели кресла;
- найти материалы, по которым было больше 10 складских движений за месяц.

Практический результат: ученик умеет строить простые отчеты по складу, производству и себестоимости.

## Модуль 4. JOIN и связи между таблицами

Цель: соединять данные из BOM, материалов, склада и производства.

Темы:

- `INNER JOIN`;
- `LEFT JOIN`;
- ключи связи;
- один-ко-многим;
- проверка потерянных строк после join.

Примеры задач:

- вывести BOM модели кресла вместе с названиями материалов;
- показать остатки по материалам из конкретной спецификации;
- найти строки BOM, для которых нет актуальной цены материала;
- сравнить план выпуска из `production_plan` с фактом из `production_output`;
- вывести список материалов, которые есть в BOM, но отсутствуют на складе.

Практический результат: ученик умеет собирать целостную картину из нескольких производственных таблиц.

## Модуль 5. Расчет потребности материалов

Цель: рассчитывать потребность материалов под план производства.

Темы:

- join плана производства с BOM;
- расчет `planned_quantity * quantity_per_unit`;
- группировка потребности по материалам;
- сравнение потребности с остатками;
- расчет дефицита.

Примеры задач:

- рассчитать потребность ткани на недельный план выпуска;
- посчитать потребность фанеры, металлокаркасов и фурнитуры по моделям;
- найти материалы, которых не хватает для выполнения плана;
- рассчитать запас после выполнения плана;
- сформировать список материалов для закупки.

Практический результат: ученик умеет делать один из главных производственных отчетов: потребность материалов по плану.

## Модуль 6. Себестоимость и нормы расхода

Цель: анализировать себестоимость кресел через материалы и нормы.

Темы:

- расчет материальной себестоимости;
- join BOM с ценами материалов;
- группировка себестоимости по модели;
- сравнение версий BOM;
- анализ отклонений нормы.

Примеры задач:

- рассчитать материальную себестоимость каждой модели кресла;
- найти самые дорогие материалы в структуре себестоимости;
- сравнить себестоимость двух версий BOM;
- найти модели, где доля ткани в себестоимости выше 40%;
- проверить строки BOM с нулевой или отсутствующей нормой расхода.

Практический результат: ученик умеет использовать SQL для экономического анализа моделей и заказов.

## Модуль 7. Подзапросы и CTE

Цель: писать читаемые многошаговые запросы.

Темы:

- подзапросы в `WHERE`;
- подзапросы в `FROM`;
- `WITH` / CTE;
- декомпозиция сложного расчета;
- повторное использование промежуточных результатов.

Примеры задач:

- через CTE рассчитать плановую потребность материалов и сравнить ее с остатками;
- найти материалы дороже средней цены в своей категории;
- построить расчет себестоимости модели в несколько понятных шагов;
- выделить активные BOM и использовать их в основном запросе;
- подготовить выборку для n8n-уведомления о дефиците материалов.

Практический результат: ученик умеет превращать сложные производственные расчеты в понятные SQL-блоки.

## Модуль 8. Оконные функции

Цель: анализировать динамику и отклонения без потери детализации.

Темы:

- `OVER`;
- `PARTITION BY`;
- `ORDER BY` внутри окна;
- `ROW_NUMBER`;
- `LAG`, `LEAD`;
- накопительные суммы.

Примеры задач:

- показать изменение цены материала по датам закупки;
- найти последнюю цену каждого материала;
- рассчитать накопительный выпуск по производственному заказу;
- сравнить текущий остаток материала с предыдущим днем;
- ранжировать материалы по вкладу в себестоимость модели.

Практический результат: ученик умеет анализировать динамику производства, цен и запасов.

## Модуль 9. Качество данных

Цель: находить ошибки в справочниках и производственных данных.

Темы:

- проверки на дубли;
- проверки на пропуски;
- несогласованные справочники;
- отрицательные остатки;
- некорректные даты;
- контрольные SQL-запросы.

Примеры задач:

- найти дубли материалов по артикулу;
- найти BOM без строк;
- найти производственные заказы без фактического выпуска;
- найти материалы с отрицательным остатком;
- найти движения склада с датой раньше создания материала;
- найти модели кресел без активной спецификации.

Практический результат: ученик умеет писать SQL-проверки, которые можно запускать вручную или через n8n.

## Модуль 10. PostgreSQL для автоматизации

Цель: подготовить SQL к использованию в отчетах, n8n и AI-автоматизации.

Темы:

- `VIEW`;
- материализованные представления на уровне концепции;
- параметры запроса;
- экспорт результатов;
- безопасные read-only запросы;
- структура SQL для автоматического запуска.

Примеры задач:

- создать запрос для ежедневного отчета по дефициту материалов;
- подготовить выборку для n8n-уведомления о критических остатках;
- собрать отчет план-факт выпуска за вчера;
- подготовить таблицу отклонений себестоимости;
- сформировать список материалов для проверки экономистом.

Практический результат: ученик умеет писать запросы, которые можно встроить в регулярные автоматизации.

## Итоговый учебный проект

Проект: SQL-отчет для планирования материалов на производство офисных кресел.

Задачи проекта:

1. Выбрать план выпуска из `production_plan`.
2. Найти активные BOM для моделей кресел.
3. Рассчитать потребность материалов по каждой модели.
4. Сгруппировать общую потребность по материалам.
5. Сравнить потребность с остатками склада.
6. Рассчитать дефицит и излишек.
7. Добавить цены материалов.
8. Оценить стоимость закупки недостающих материалов.
9. Сформировать итоговый отчет для экономиста.
10. Подготовить запрос для запуска через n8n.

Критерий завершения: ученик может самостоятельно написать SQL-запрос, который показывает, какие материалы нужны для выполнения производственного плана, сколько их не хватает и какая ориентировочная сумма закупки потребуется.

## Рекомендуемый порядок практики

1. Каждый модуль завершать 5-10 задачами на мебельных данных.
2. Каждый новый запрос связывать с реальной рабочей ситуацией.
3. Сохранять удачные запросы как шаблоны для отчетов.
4. После модуля 5 начать собирать личную библиотеку SQL для автоматизации.
5. После модуля 10 подключать лучшие запросы к n8n-сценариям.
