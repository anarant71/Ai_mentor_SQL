# AI Mentor

AI Mentor - проект образовательного AI-наставника, который помогает пользователю проходить уроки, получать персональные задания и автоматизировать учебные сценарии через backend, frontend, базу данных и n8n-процессы.

## Назначение

Проект предназначен для построения платформы, где пользователь может:

- изучать материалы по урокам;
- получать задания и рекомендации;
- взаимодействовать с AI-наставником;
- отслеживать прогресс обучения;
- использовать автоматизации для уведомлений, проверок и персональных сценариев.

## Структура проекта

```text
AI-Mentor/
├── backend/      # Серверная логика, API, интеграции с AI-сервисами
├── frontend/     # Пользовательский интерфейс
├── database/     # Схемы, миграции, сиды и материалы для базы данных
├── docs/         # Расширенная документация проекта
├── lessons/      # Учебные материалы и сценарии уроков
├── tasks/        # Задания, упражнения и шаблоны задач
├── n8n/          # Автоматизации и workflow для n8n
└── roadmap.md/   # Материалы дорожной карты проекта
```

## Основные модули

### Backend

Отвечает за бизнес-логику проекта: обработку запросов, работу с пользователями, хранение прогресса, выдачу уроков и заданий, а также интеграции с AI-моделями и внешними сервисами.

### Frontend

Содержит интерфейс пользователя: страницы уроков, задания, чат или окно общения с наставником, профиль и элементы навигации по обучению.

### Database

Хранит структуру данных проекта: пользователей, уроки, задачи, результаты, историю взаимодействий и настройки персонализации.

### Lessons

Каталог для учебного контента. Здесь можно размещать Markdown-файлы, JSON-сценарии, примеры, материалы для самостоятельной работы и методические заметки.

### Tasks

Каталог для практических заданий, проверочных упражнений и шаблонов задач, которые AI-наставник может выдавать пользователям.

### n8n

Каталог для workflow автоматизаций: напоминаний, рассылок, проверки статусов, синхронизации данных и дополнительных сценариев вокруг обучения.

## Быстрый старт

На текущем этапе репозиторий содержит базовую структуру проекта. После добавления технологического стека рекомендуется дополнить этот раздел конкретными командами запуска.

Ожидаемый сценарий запуска:

```bash
# 1. Установить зависимости backend
cd backend

# 2. Установить зависимости frontend
cd ../frontend

# 3. Подготовить базу данных
cd ../database

# 4. Запустить frontend и backend
```

## Конфигурация

Рекомендуется хранить локальные переменные окружения в `.env`-файлах, не добавляя их в репозиторий.

Типовые переменные:

```env
APP_ENV=local
DATABASE_URL=
OPENAI_API_KEY=
N8N_WEBHOOK_URL=
JWT_SECRET=
```

1. Зафиксировать технологический стек backend и frontend.
2. Добавить модель данных и миграции.
3. Описать формат уроков и заданий.
